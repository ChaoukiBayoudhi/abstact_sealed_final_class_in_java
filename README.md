# Abstract sealed final class in Java

Java example code (plain Java, no framework).

## Tech stack

- Java
- Lombok

## Concepts covered

Abstract classes, inheritance, sealed classes.

## Project structure

- `src`: Disk, Main, Point, Rectangle, Shape, Square, Triangle

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run the class that contains the `main` method.

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
